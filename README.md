# Jo Dailies

Track Jo’s daily puzzles with streaks, a month calendar, and a little Calcifer buddy who reacts as you go.

Open Connections, Stackdown, Chess Daily, and Waffle — mark them done, keep a golden-day streak, and poke at a few extra checkboxes just for fun. Progress lives in `localStorage`.

## Features

- Open each daily and auto-mark it done (manual override anytime)
- Month calendar tinted by completion (partial vs golden all-four)
- General streak (any daily) + Golden streak (all four)
- Calcifer moods, quotes, and idle animations
- Progress saved in `localStorage` (no backend)

## Setup

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — typecheck and production build
- `npm test` — run Vitest unit tests
