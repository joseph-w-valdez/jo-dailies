# joha-dailies

A single-page tracker for your daily puzzles — Connections, Stackdown, Chess.com Daily, and Waffle.

## Features

- Open each daily in a new tab and auto-mark it done (manual override anytime)
- Month calendar tinted by completion (partial vs golden all-four)
- General streak (any daily) + Golden streak (all four)
- Progress saved in `localStorage` (no backend)

## Setup

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — typecheck and production build
- `npm test` — run Vitest unit tests
